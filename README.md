# RUMBO · Web de viajes

Todos los archivos de la página están en esta carpeta.

## Compartir por Wi‑Fi

Abre PowerShell en esta carpeta y ejecuta:

```powershell
py -m http.server 8000
```

Busca tu dirección IPv4 con `ipconfig` y comparte esta dirección: `http://TU-IP-LOCAL:8000` (por ejemplo, `http://192.168.1.35:8000`). Mantén PowerShell abierto y permite el acceso en redes privadas si Windows muestra el aviso del firewall.
